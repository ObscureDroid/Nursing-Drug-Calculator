# Nursing Drug Calculator

A simple and beginner-friendly nursing drug dosage calculator designed to help nursing students practice common medication and IV dosage calculations.

## Features

- 💊 Tablet and capsule dosage calculation
- 💉 Injectable medication dosage calculation
- 💧 IV flow rate calculation
- ⏱️ IV infusion time calculation
- 🧮 Basic dosage formula practice

## Important Disclaimer

This project is intended for **educational and practice purposes only**. It should not be used as a substitute for clinical judgment, professional medical advice, or hospital-approved medication calculation procedures.

Always verify medication orders and calculations according to your institution's policies and guidelines.

## Formula

### Dosage Calculation

**Desired Dose ÷ Available Dose × Quantity = Amount to Administer**

Example:

Desired dose: 500 mg  
Available dose: 250 mg per tablet  

500 ÷ 250 × 1 tablet = **2 tablets**
